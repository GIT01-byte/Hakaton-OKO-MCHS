# Око МЧС: панель мониторинга (React + Leaflet)

Панель получает данные из API бэкенда (тот же origin; в dev `/api` и `/media` проксируются на порт 8000).

## Команды
```
npm install     # установить зависимости
npm run dev     # режим разработки (http://localhost:5173, прокси на бэкенд)
npm run build   # сборка -> dist/ (бэкенд отдаёт её сам на /)
```

Собранная панель лежит в `dist/` и отдаётся FastAPI на http://localhost:8000/ — отдельный веб-сервер не нужен.
